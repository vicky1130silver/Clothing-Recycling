# 衣循环小程序电商用户行为分析

## 定位与真实性

这是围绕旧衣回收小程序“二手商城”业务设计的分析作品，第一负责人为朱怡筠。商城业务方案并不构成已经上线的证明。真实数据来自REES46公开的普通多品类电商平台，筛选其服饰类；公开数据不证明二手衣物行为。分析用于验证可迁移的方法，运营结论需要在未来小程序上验证。原557份问卷是不同的调查资料，未与公开交易数据混算或关联用户身份。本作品不补写未经证实的竞赛奖项。

## 数据来源与筛选

- 发布方：https://rees46.com/en/datasets
- 官方文件：https://data.rees46.com/datasets/marketplace/2019-Oct.csv.gz
- Kaggle说明：https://www.kaggle.com/datasets/mkechinov/ecommerce-behavior-data-from-multi-category-store
- 条件：category_code以apparel.开头，2019-10-01≤event_time<2019-10-15，时间UTC。
- 从官方压缩文件按时间顺序读取至10月15日边界，不下载或分析其余日期。选出545,473条原始服饰事件，清洗后545,468条，108,047名用户。
- 清洗后范围：2019-10-01 00:00:10 至 2019-10-14 23:59:50 UTC。
- 来源标识、提取范围、文件SHA256见source_manifest.json。此处范围是按类目和日期限制，不是随机抽样。

## SQL与Python实际完成的工作

1. SQL用ROW_NUMBER按9个源字段去重，校验关键标识、事件类型、价格和日期。标识用文本，避免19位category_id精度损失，价格转换整数分避免浮点金额累计误差。原始行不覆盖。
2. 同一user_id、user_session、product_id先找view，再找其后或同秒purchase。服饰子集没有cart事件，采用两步漏斗，不能把加购率视作0，也不能判断加购阶段流失。单位是商品会话路径，不是用户，也不是订单。同秒允许是秒级时间精度下的明确规则，不能证明同秒内顺序。只计算同会话转化。
3. 留存队列采用首次“观察到服饰行为”的日期，并不是真实注册日。D1、D3、D7为恰好第N自然日有任意服饰行为；聚合分母仅包括有完整后续窗口的队列，不能对队列百分比做简单平均。边界缺失记为空，不是0。
4. 正价购买用户做RFM。R=2019-10-15减最近购买日。F=不同购买会话数，没有订单ID，不能称订单数。M=去重购买事件价格和，没有数量、退款或成本，不是净GMV、利润或LTV。源价格单位保留，不假定为人民币。
5. R评分：≤3天4分、≤7天3分、≤10天2分，其余1分。F评分：min(F,4)。M评分按购买用户金额的25/50/75分位区间，等于边界留在较低分位。实际业务分群使用下述明确规则，未将其冒充机器学习聚类。

## 核心结果

- 漏斗：浏览路径458,220，浏览后购买2,426，路径转化0.53%。当前子集无加购事件，不能定位三步漏斗的加购流失。浏览至购买路径流失为，99.47%。
- D1回访：3,731/100,236=3.72%。
- D7回访：1,103/44,913=2.46%。只纳入10月7日及之前首见用户。
- 正价购买用户1,794名，M金额总和204,577.65。Top20%按金额降序取ceil(购买用户数×20%)，贡献45.71%，是窗口观察而非长期价值预测。
- M的P75=127.42。核心价值：R≤7、F≥2、M≥P75。潜力复购：R≤7、F≥2其余。近期首购：R≤7、F=1。待唤回：R>7。互斥覆盖全部正价购买用户。没有人为补造分群人数。

## 三条运营建议

1. 详情页前置成色、瑕疵、尺码、卫生处理和运费说明，对照测试加购与购买路径转化。
2. 对近期首购者测试收货关怀、同尺码上新提醒，跟踪完整D7队列与退订率。
3. 对高价值群体测试尺码订阅与优先上新，设置对照组，补齐成本和退款后评估净收益。

这些是迁移假设，未实施，没有增长百分点、收入提升或已完成平台转化的声明。公开记录中不存在回收重量、捐赠、清洗验质或旧衣成色，未推造这些结果。
